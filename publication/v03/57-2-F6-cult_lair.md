#### Артефакт: череп святого Маврикия

| Параметр         | Значение                                                             |
|------------------|----------------------------------------------------------------------|
| Название         | Череп святого Маврикия (ковчег)                                      |
| Тип              | Уникальный артефакт (реликвия Ордена Вечной Розы)                    |
| Редкость         | Уникальный                                                           |
| Уровень предмета | — (артефакт; по усмотрению Мастера)                                  |
| Использование    | Реликвия; аура                                                       |
| Радиус           | 100 футов                                                            |
| Состояние        | Печать Бафомета сломана; аура активна                                |
| Активация        | Пассивно                                                             |
| Материал         | Дерево, позолоченный металл, перламутр, шёлк, мумифицированный череп |

**Свойства:**

- **Вдохновение святого.** Пока вы находитесь в пределах 100 футов от ковчега, при проверке **Ремесла** или
  **Выступления**, связанной с творческой деятельностью (живопись, пение, музыка, скульптура, поэзия, танец и т.п.),
  результат считается на одну ступень успеха выше: критический провал → провал, провал → успех, успех → критический
  успех. Эффект применяется после всех модификаторов и не может поднять результат выше критического успеха.
- **Благословение мастера.** Пока вы находитесь в пределах 100 футов от ковчега и успешно проходите проверку Ремесла для
  создания предмета, качество получившегося предмета повышается на одну ступень: низкокачественный (shoddy, -2) →
  обычный → мастерски изготовленный (+1) → легендарный (+2).
- **Только творчество.** Артефакт не помогает в утилитарных задачах: Взлом, Ремонт, создание ядов и ловушек, а также
  проверки Выступления, не связанные с творчеством, остаются без изменений.
- **Аура.** Эффект действует на всех существ в радиусе 100 футов, включая врагов и тех, кто не знает о реликвии. Аура
  исходит от ковчега и перемещается вместе с ним.
- **Сломанная печать.** Пока печать-пломба с оттиском Бафомета была цела, сила реликвии не выходила за пределы ковчега.
  Виттория сломала печать, впервые открыв ковчег в День Гнева 23 Рова 4710 года; с тех пор аура действует постоянно.
