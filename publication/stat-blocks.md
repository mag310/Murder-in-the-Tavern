# СТАТ-БЛОКИ (PF2e)

Выделены из `masters-book.md`. Все значения пересчитаны по правилам PF2e Core/Remaster.
Уровни указаны как NPC Level (не CR). Сложность встреч — по бюджету XP партии 4×5 уровня.

---

## Механика PF2e (применяется ко всем блокам)

**Ранги владения (proficiency) — всегда включают уровень персонажа:**

| Ранг      | Бонус к проверке | Эквивалент  |
|-----------|------------------|-------------|
| Untrained | −2               | Уровень − 2 |
| Trained   | +2               | Уровень + 2 |
| Expert    | +4               | Уровень + 4 |
| Master    | +6               | Уровень + 6 |
| Legendary | +8               | Уровень + 8 |

Итоговый бонус = **Уровень + бонус ранга + модификатор** (база 10 **не** добавляется к проверкам).
Ранг — это *единый* бонус: Expert = +4, а НЕ «Trained +2 + ещё +4». Не суммировать ранг и уровень дважды.

**База 10 — ТОЛЬКО у AC и DC.** У проверок (атака, спасбросок, навык, Восприятие) базы 10 НЕТ.

- **Атака** = `Уровень + ранг владения оружием + мод. (STR/DEX) + бонус предмета (+1/+2)`.
- **AC** =
  `10 + мод. DEX + бонус брони (лёгкая кожа +1, Studded +2) + бонус щита (+2) + бонус предмета (+1) + (Уровень + ранг владения бронёй)`.
    - Trained = Уровень + 2, Expert = Уровень + 4 (ранг уже включает уровень — НЕ добавлять уровень отдельно).
    - «Врасплох» (Flat-footed) = AC без бонуса DEX.
- **Спасбросок** = `Уровень + ранг (класс) + мод. характеристики`.
- **Навык** = `Уровень + ранг + мод. характеристики`.
- **Восприятие** = `Уровень + 2 (Trained) + мод. WIS` (или +4/+6/+8 при Expert/Master/Legendary).
- **СЛ (DC) способности/заклинаний** = `10 + Уровень + ранг + мод. (WIS/CHA/INT)`.
- **HP (NPC):** берётся из таблицы Building Creatures по роли (Low/Mod/High), а НЕ по формуле
  `уровень × HP класса + CON`.
- **Скрытый удар (Sneak Attack):** +1d6/+2d6/+3d6/+4d6 на 1/5/11/17 уровне (Rogue).

**Состояния (PF2e) — значения, уменьшаются/исчезают сами, НЕ «1 раунд»:**

- **Застигнут врасплох (Flat-footed)** — состояние; цель не получает бонус DEX к AC, а атакующий получает +2.
- **Замедлен (Slow 1/2/3)** — снижает число действий; длится до конца следующего хода цели.
- **Испуган (Frightened 1/2/3)** — -1/-2/-3 к навыкам; уменьшается на 1 в конце каждого хода.
- **Сбит с ног (Prone)** — +2 к атакам по цели; цель тратит действие на вставание.
- **Обездвижен (Immobilized)** — -2 к атакам навыками, которые требуют движения; **нет DC высвобождения** (это не PF2e).

**Языки (PF2e):** не привязаны к расе автоматически. Персонаж знает Общий + 1 (или больше) от фитов/Интеллекта; расовые
языки (Эльфийский, Небесный и др.) — только при наличии соответствующего фита/навыка.

**«Действия логова» (Lair Actions) — НЕ механика PF2e.** Заменены на реакции, ауры или фазовые события боя (hazards /
environmental effects).

**Создание NPC (PF2e Gamemastery Guide, «Building Creatures»):** NPC имеют **монолитные** статы, подобранные по таблице
под их роль (Soldier, Brute, Spellcaster, Sniper, Controller и т.п.), а НЕ по формулам создания персонажей игроков (без
кубиков HP и ancestry HP). Атака/DC/AC/HP берутся из диапазонов таблицы.

**Урон в ближнем бою:** к базовому кубикам оружия **всегда** добавляется модификатор ключевой характеристики
(Сила/Ловкость/Интеллект при наличии Thief/Mastermind/Investigator).

**Типы урона (PF2e Core / Remaster):**

- Призраки наносят **Void damage** (в Remaster — ранее Negative; в Core — Void/Force), НЕ Spirit.
- Spirit/positive damage — только у специальных способностей (Divine Smite у Champion и т.п.).
- «+1d10 урона по культистам» — не PF2e; реликвии/оружие используют свойства **Bane** (против определённой группы) и
  **Holy** (против проклятых).

**Devise a Stratagem (Investigator):** при разработке стратегии атака по выбранной цели использует **модификатор
Интеллекта** вместо модификаторов Силы/Ловкости, а стратегический удар наносит дополнительный урон.

**Ожидаемая сложность встреч:** 4×5 уровень — средняя сложность для группы 4×5.
