# План доработки сценария «Убийство в таверне»

## 1. Утверждение канона (Story Decisions)

> Оставшиеся решения автора (остальное уже канон).

- [ ] **Личности персонажей** — придумать и вписать имена для 6 основных NPC (Трактирщик, Моряк, Официантка, Врач,
  Детектив, Художник) и для контекстных NPC без имени (Капитан корабля; Мэр = Абериан Арванкси, Ликтор = Ришемар
  Альмансор, Паравикар = Дарсин Ренс, Шериф = Ильтус Мартис — уже заданы).
- [ ] **Название корабля** — придумать и вписать в `characters/sailor.json` / `characters/ship_captain.json`.
- [ ] **Дополнительные связи** — Моряк (помимо дезертирства, кражи казны, убийства жены); Художник (дополнительные
  жертвы/мотивы). Записать в `characters/sailor.json` / `characters/artist.json`.
- [ ] **Таймер 24 часа — реальное или сжатое время** — сейчас `flood_mechanic.timer` = игровые часы, не привязано к
  реальному. Решает автор.

## 2. Наполнение данных (Data Filling)

> Заполнение полей, которые сейчас содержат `null` или `needs_definition`.

- [ ] **Содержимое улик** — пройти по `evidence.json`, заполнить `content`/`description` (текст письма, описание пятна и
  т.д.) и проверить `interpretation` + `false_leads`.
- [ ] **Матрицы убийства** — пройти по `murder_matrix.json`; для каждой жертвы (d6) проверить `false_leads`,
  `required_evidence` (связь с ID из `evidence.json`), `special_consequences`.

## 3. Техническая валидация (Tech Check)

- [ ] **JSON Schema Validation** — валидация всех файлов `characters/`, `locations/`, `organizations/`, `evidence.json`,
  `murder_matrix.json` по их `*.schema.json`.
- [ ] **Согласованность расписаний** — `daily_schedule` всех основных персонажей (нет конфликта `time` + `location`);
  контекстные NPC — `daily_schedule: null` / только `daily_schedule_note`; призраки — `can_be_murder_victim: false`.
- [ ] **Изоляция и локации** — все `gameplay`-локации имеют корректный `parent_location`; игроки не покидают таверну до
  конца.
- [ ] **Статусы жертв** — `can_be_murder_victim: false` у контекстных NPC, Шерифа (`main_npc`) и призраков; они не
  фигурируют как `victim` в `murder_matrix.json`.
- [ ] **Экипаж корабля** — `doctor` имеет `status: left` в `organizations/ship_crew.json` и `characters/doctor.json`.

## 4. Логика (Logic Audit)

- [ ] **Принцип «Не любое преступление = убийство»** — контрабанда/культ/пьянство не автоматически обвиняют в текущем
  убийстве; в `evidence.json` указано, чего они НЕ доказывают.
- [ ] **Логика детектива** — `investigation` не противоречит нанимателю (`primary: sheriff`); `false_beliefs` не
  блокируют расследование.

## 5. Публикация

- [ ] Проверить, что все JSON-файлы валидны и согласованы.
- [ ] Сгенерировать финальную версию сценария (если используется генератор).
